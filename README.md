One line, at most 120 characters: the error message a kitchen toaster shows its owner when something goes wrong.

> ERROR 07: your bagel is on fire. I ejected it at 07:12, but the smoke alarm already knows. Please unplug me gently.

The bagel caught fire, the toaster did its job, and now it is staging a small tragedy — quietly dramatic, apologetic to the end.

## Run

```sh
python3 main.py
```

`main.py` gates the line (one line, 1–120 chars, not whitespace-only), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), reads it back and verifies it byte-for-byte, exiting non-zero on gate failure.
